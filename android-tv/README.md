# VELORA Android / Google TV Launcher

This is a separate TV-only launcher. It does not replace or modify the normal phone, tablet, or desktop experience.

The launcher opens:

`https://glenroygriffiths876-collab.github.io/VELORA-TV/?tv=1`

The `tv=1` flag activates VELORA's isolated 10-foot UI, D-pad focus navigation, remote Back handling, and TV-only spacing.

## Build

Open the `android-tv` folder in Android Studio and build the APK, or use the repository's **Android TV APK** GitHub Actions workflow.

The app is declared as a Leanback launcher application and does not require a touchscreen.
